# 🃏 JavaScript Blackjack

A Blackjack game built with JavaScript and Vite. This project is part of my journey to become a Full Stack Developer.

## 📸 About the Project

This project implements the basic logic of a Blackjack game, where the player competes against the computer.

## 🚀 Technologies

- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Git & GitHub

## ✨ Features

- Random card deck generation.
- Card shuffling.
- Player card drawing.
- Automatic computer turn.
- Card value calculation.
- Score tracking.
- Blackjack game logic.

## 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/Crishuezo1702/js-vite-blackjack.git
```

Navigate to the project directory:

```bash
cd js-vite-blackjack
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
